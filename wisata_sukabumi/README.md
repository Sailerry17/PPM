# Wisata Sukabumi

Aplikasi Flutter: jelajah 10 destinasi di Sukabumi, simpan favorit, dan susun rencana kunjungan.

## Cara menjalankan
Pastikan Flutter sudah terpasang (`flutter doctor`) dan emulator/HP tersambung, lalu di folder ini:

- Windows: klik dua kali `run.bat` (atau jalankan di terminal)
- macOS/Linux: `bash run.sh`

Skrip akan membuat folder platform (android/ios) pada run pertama, mengunduh dependensi, lalu menjalankan aplikasi.

Manual: `flutter create --project-name wisata_sukabumi . && flutter pub get && flutter run`

Catatan: biaya yang tampil hanya perkiraan. Data hilang saat aplikasi ditutup.
